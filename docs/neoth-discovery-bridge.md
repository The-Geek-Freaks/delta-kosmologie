# NEOTH Discovery Bridge

Delta Cosmology and [NEOTH](https://github.com/The-Geek-Freaks/NEOTH) should
link to each other explicitly.

The goal is not only navigation. It also makes GitHub search understand that:

- Delta Cosmology provides the RDelta/Babel framework.
- NEOTH is the operational LLM/agent runtime testbed.
- The Babel Index is intended to become a NEOTH telemetry probe.

## Link From Delta Cosmology To NEOTH

This repository already links NEOTH from:

- `README.md`
- `docs/overview.md`
- `docs/neoth-integration.md`
- `protocols/pilot-b-neoth.md`
- `schemas/neoth-babel-event.schema.json`
- `metadata/repository-metadata.yml`

## Recommended NEOTH README Snippet

Add this to the NEOTH README:

```markdown
## Delta Cosmology / Babel Index Testbed

NEOTH is the first planned runtime testbed for
[Delta Cosmology](https://github.com/The-Geek-Freaks/delta-kosmologie), a
preformal framework around RDelta, the Babel Index, and loss of productive
difference in complex agentic systems.

The planned NEOTH probe will observe orchestration events asynchronously and
test whether a structured Babel score predicts agent loops, tool fragility,
context degeneration, timeout cascades, and fallback collapse beyond standard
runtime telemetry.
```
