# Overview

Delta Cosmology is a preformal framework for thinking about observable
structure as the co-condition of recursion and difference.

The framework has two intentionally separate branches:

| Branch | Status | Success criterion |
| --- | --- | --- |
| Conceptual framework | Preformal / speculative | Internal coherence, clear boundaries, no physics category errors |
| Babel Index instrumentation | Empirical / testable | Out-of-sample predictive value beyond strong baselines |

## The Core Move

Difference without recursion is unstable. Recursion without difference is
indistinguishable. Delta Cosmology calls their co-condition **RDelta**.

The practical claim is narrower:

> Complex systems degrade when coupling, convergence pressure, resource
> pressure, agent density, and information velocity outrun differentiation and
> redundancy.

That degradation is called **Babel**.

## Why LLM Agents Matter

Agentic LLM systems make this observable. They expose:

- tool chains,
- context windows,
- retry behavior,
- subagent density,
- fallback routes,
- output similarity,
- task outcome labels.

That makes them suitable for a hard test: can a structured Babel feature predict
near-future failure better than ordinary telemetry features alone?

## The NEOTH Testbed

[NEOTH](https://github.com/The-Geek-Freaks/NEOTH) will test the framework at the
runtime level. The planned module is an asynchronous observer that watches
orchestration events and computes rolling-window features.

The observer is not a belief engine. It is a falsifiable telemetry probe.
