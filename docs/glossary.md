# Glossary

| Term | Meaning |
| --- | --- |
| RDelta | The co-condition of recursion and difference. |
| Difference | A distinction, boundary, or separability condition. |
| Recursion | A return, memory, stabilization, or repeatable structure. |
| Babel | Loss of productive difference in a communication, cooperation, or control system. |
| Babel Index | A domain-specific engineered feature for Babel risk. |
| Productive difference | Difference that still enables work, learning, coordination, or adaptation. |
| Coupling degree | How tightly components depend on each other. |
| Convergence pressure | Pressure toward sameness, loop states, or semantic concentration. |
| Resource pressure | Context, queue, latency, cost, timeout, or optimization stress. |
| Agent density | Number of active autonomous actors or subagents. |
| Information velocity | Rate of messages, tokens, requests, commits, or events. |
| Differentiation capacity | Ability to keep roles, meanings, tools, and tasks distinct. |
| Heterarchy | Redundant, modular, non-single-point route structure. |
| Nested feature test | Test where the Babel feature must improve a baseline that already has the raw variables. |
| Domain firewall | Rule that success in one domain validates only that local model. |
| NEOTH | The first planned LLM/agent runtime testbed for the Babel Index. |
