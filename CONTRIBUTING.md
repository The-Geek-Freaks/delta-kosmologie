# Contributing

Contributions are welcome if they sharpen the framework, reduce ambiguity, or
make empirical testing harder to fool.

Good contributions:

- identify unclear operational definitions,
- add null models,
- add falsification criteria,
- improve schema precision,
- separate interpretation from measurement,
- report reproducible issues in the paper or protocols.

Weak contributions:

- treat structural analogy as proof,
- remove domain-firewall language,
- add post-hoc fitting rules,
- generalize one pilot result across all domains.

## Review Standard

Every empirical change should answer:

1. What is measured?
2. What would falsify it?
3. Which simpler local model must it beat?
4. Which claim boundary prevents overreach?
