# Quick Start

## What This Is

Delta Cosmology is a framework for studying when complex systems lose
productive difference. In the LLM/agent branch, that loss becomes observable as
context degeneration, tool-chain fragility, agent loops, retry storms, timeout
cascades, and fallback collapse.

## What To Read First

1. Read the repository README for the public overview.
2. Read [[Framework Map|Framework-Map]] to understand the layers.
3. Read [[Babel Index|Babel-Index]] for the telemetry score.
4. Read [[NEOTH Pilot|NEOTH-Pilot]] for the first runtime experiment.
5. Read [[Falsification Standard|Falsification-Standard]] before making claims.

## Minimal Mental Model

```text
Difference + Recursion
        -> RDelta
        -> Babel Index
        -> NEOTH telemetry probe
        -> nested prediction tests
        -> supported, inconclusive, or falsified
```
