# Glossary

## RDelta

The co-condition of recursion and difference used as the framework primitive.

## Difference

Distinction, boundary, separability, and productive non-identity.

## Recursion

Memory, return, stabilization, and repeated transformation through time.

## Babel Index

A domain feature family for detecting loss of productive difference.

## Productive Difference

Useful separation between agents, prompts, tools, roles, routes, or semantic
states. In an LLM runtime, productive difference is lost when outputs converge,
fallbacks collapse, contexts degenerate, or agents loop.

## NEOTH

The first intended LLM/agent runtime testbed for Babel telemetry.

## Nested Falsification

The rule that each domain claim must be tested locally against raw controls,
null models, and out-of-sample splits before broader interpretation is allowed.
