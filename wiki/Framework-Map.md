# Framework Map

![RDelta framework map](https://raw.githubusercontent.com/The-Geek-Freaks/delta-kosmologie/main/assets/rdelta-framework-map.svg)

## Layers

| Layer | Role | Claim Type |
| --- | --- | --- |
| Difference | Distinction, boundary, separability | Preformal operator |
| Recursion | Memory, return, stabilization | Preformal operator |
| RDelta | Co-condition of observable structure | Framework primitive |
| Babel Index | Domain-specific degradation feature | Empirical instrument |
| NEOTH Probe | Runtime telemetry implementation | Engineering testbed |
| Nested falsification | Model comparison and null tests | Scientific boundary |

## Key Design Choice

The framework does not ask readers to accept the cosmological reading first. It
forces a local engineering instrument first. If that instrument fails to predict
runtime degradation beyond normal telemetry, the Babel-ratio structure fails in
that domain.
