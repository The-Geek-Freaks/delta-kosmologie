# Security Policy

This repository does not currently ship executable production software.

For issues related to the NEOTH runtime itself, report them in the NEOTH
repository:

https://github.com/The-Geek-Freaks/NEOTH

For issues in this repository:

- open a GitHub issue for documentation or protocol problems,
- avoid posting secrets, private telemetry, API keys, or personal data,
- anonymize runtime logs before attaching examples.
